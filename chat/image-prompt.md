# 生图提示词：把白模图变成效果示意

先在「改改你的家」里导出一张白模图：切到 3D，用「平视」转到想看的角度；左侧工具栏点「白模」，再点「导出图片」，背景选「纯白」、画幅选「16:9」，点「导出 PNG」。然后挑一个模板：

- **模板 A**：只发白模图一张，用文字描述你想要的风格。
- **模板 B**：发白模图，再加一张你喜欢的室内照片当风格参考。

把模板整段复制，替换方括号 `[ ]` 里的内容（连方括号一起换掉），和图片一起发给一个能生成图片的 Chat。不知道怎么填的方括号，删掉那一行就行。

---

## 模板 A：白模图 + 风格描述

```text
附图是我家一个房间的 3D 白模渲染图：墙、门、窗、梁的位置和大小都是按户型图做出来的，是真实结构。

任务：照着这张白模图，生成同一个机位的照片级室内效果图。只改材质、颜色和光照，不改任何几何。

【画面】构图和附图完全一样：不裁切、不放大缩小、不旋转、不改透视。输出 16:9 横图；附图不是 16:9 时，在边缘补出同样的墙面、地面或天花，不新增任何东西。

【这是哪里】[房间和视角，例如：客厅，人眼高度平视，站在入户门一侧往阳台看]

【画面里的门窗】[按从左到右写，例如：左侧墙上一樘通往阳台的落地推拉门；右侧墙上一扇普通窗，窗台离地约 90 cm。画面里只有这两处门窗。]

【不能动的】每一面墙、每一个墙角的位置；每一扇门、窗、门洞的数量、位置、宽度、高度和窗框分格；梁的位置。
不得新增任何窗、门、洞口、落地窗、隔断或墙；白模里没有的窗和门一律不能出现；不得删除或合并白模里的门窗；不得把窗画成柜门、墙板或装饰画。

【可以改的】只改表面：[风格描述，例如：奶油原木风，浅橡木地板，奶油白墙面和天花，哑光金属细节；上午柔和的自然光从窗户进来，室内明亮、阴影柔和。]

【不要加的】不加窗帘、百叶、纱帘、帘杆，窗框和窗外要露出来。不加家具和大件摆设。不加人、不加文字、不加水印。
```

## 模板 B：白模图 + 你喜欢的风格照片

发图顺序：**第一张白模图，第二张风格照片**。

```text
两张附图。图1 是我家一个房间的 3D 白模渲染图：墙、门、窗、梁的位置和大小都是按户型图做出来的，是真实结构。图2 是一张我喜欢的室内照片，拍的是别人家的另一个房间，只当风格参考。

任务：照着图1，生成同一个机位的照片级室内效果图。房间的几何只看图1；配色、材质和光线氛围照图2 的感觉来。只改材质、颜色和光照，不改任何几何。

【画面】构图和图1 完全一样：不裁切、不放大缩小、不旋转、不改透视。输出 16:9 横图；图1 不是 16:9 时，在边缘补出同样的墙面、地面或天花，不新增任何东西。

【这是哪里】[房间和视角，例如：主卧，人眼高度平视，站在门口往窗户看]

【画面里的门窗】[按从左到右写，例如：左边一樘飘窗，窗台离地约 45 cm；右边墙上一扇普通窗。画面里只有这两扇窗，没有门。]

【不能动的】每一面墙、每一个墙角的位置；每一扇门、窗、门洞的数量、位置、宽度、高度和窗框分格；梁的位置。
不得新增任何窗、门、洞口、落地窗、隔断或墙；图1 里没有的窗和门一律不能出现；不得删除或合并图1 里的门窗；不得把窗画成柜门、墙板或装饰画。
图2 是别的房间：不要照搬图2 的窗、门、拱门、墙、梁的位置和形状，不要照搬图2 的构图和机位，也不要把图2 里的家具和摆件搬进来。

【可以改的】只改表面：墙面、地面、天花的材质和颜色，以及光线和氛围，都照图2 的感觉。[可选：补一句你特别在意的，例如：图2 里的陶土色只用在点缀上，墙面还是浅色。]

【不要加的】不加窗帘、百叶、纱帘、帘杆，窗框和窗外要露出来。不加家具和大件摆设。不加人、不加文字、不加水印。
```

## 出图以后

- **出来的图是效果示意，尺寸以平面和立面为准。** 不要拿它量尺寸、定家具大小。
- **先对一遍墙窗门**：和白模图并排看，墙角、门窗的数量和位置是不是一样，窗有没有被画成柜子或墙。不对就换一次再出；还不对，就换个模型试试。
- 用了模板 B，如果整个房间被重新画了一遍（墙、窗位置都变了），改用模板 A，把照片里的感觉用文字写进「可以改的」那一行。
- 风格照片只取氛围。模型常会把颜色放大，比如把点缀色刷满整面墙；具体颜色以你选的材料为准。
- 网页版没有自动打分，只能靠你对着白模图看。装了 Skill 的 Agent 版会自动打分、不过就换输入重出（先给白模、深度、线稿三张，不过再只给白模），最多重试 2 次。
- 这些模板怎么来的：实验记录（提示词全文、输入、产图、分数）在 https://github.com/ai-azhou/see-your-home/tree/main/evidence/generation 。每种组合只有两张图，只能看方向。
- 图片会发给你用的那个 Chat 服务。白模图里只有墙和门窗，没有户型图上的文字，但它仍是你家的结构，发不发由你决定。
