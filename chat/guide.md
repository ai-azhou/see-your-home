# 在网页 Chat 里用「看见你的家」

不用装任何东西：用网页上的 AI 对话（网页版或手机 App 都行）把户型图读成结构方案，再用离线网页工具「改改你的家」（try-your-home）看叠图、看 3D、试拆墙、导出白模图和改造清单 PDF。

这是按图读出的结构，不是施工图。哪面墙承重、能不能拆，要以物业、结构图和专业人员的结论为准。

**网页 Chat 没有沙盒，跑不了程序**：它只能看图、写文字，读出的墙、门窗位置和尺寸可能不准。校验、叠图、3D、导出图片都在「改改你的家」里做，有问题再贴回给 Chat。**有条件的话，优先用 Agent 版。**装了 Skill 的 Agent 版（Claude Code、Codex 这类能跑程序的 Agent）会自己校验、自己出 3D 和白模图，见[仓库首页](../README.md)。

## 整个流程

1. 让 Chat 读图，给出一份结构方案（一大段代码）。
2. 把方案粘进「改改你的家」，叠图核对、看 3D。
3. 回答 Chat 的问题；对不上的地方从工具里复制出来贴回去，Chat 改好再给一份。
4. 之后随你选：试拆墙、改门窗；导出白模图去生成「装好大概什么感觉」的效果示意图；在工具里导出改造清单 PDF。只想要结构，做到第 3 步就行。

Chat 第一次回复会先讲一遍这个路线，末尾附「改改你的家」的下载和用法；之后每次回复末尾都有「下一步你可以」，照着选就行。忘了工具怎么用，随时问它「怎么用」。

## 你需要准备

1. **一个能看图的网页 Chat**：能上传图片、能读图片内容的 AI 对话。
2. **「改改你的家」**：一个网页文件，下载后双击就能在浏览器里打开，不联网、不用安装。下载：在 GitHub 打开 [try-your-home.html 的文件页](https://github.com/ai-azhou/try-your-home/blob/main/try-your-home.html)，点右上角「Download raw file」（下载原始文件）；GitHub 打不开就用 [Gitee 镜像](https://gitee.com/gevoll/try-your-home)，同样打开 try-your-home.html 下载原始文件。工具的完整用法见 [USAGE.md](https://github.com/ai-azhou/try-your-home/blob/main/docs/USAGE.md)。
3. **你的户型图**：开发商或房产平台的户型图最好；手机拍的也行，尽量正对着拍、拍全。

## 第 1 步：让 Chat 读图（两种启动方式选一种）

先**新开一个对话**。

**建议打开「深度思考 / 长思考」这类模式**（各家叫法不同）。读户型图要算比例、对坐标，快速模式常常写不对完整方案，只能给出简版（见下面「简版方案」）。

**A. 一句话启动（Chat 能联网读网页时）**：上传户型图，同一条消息里发这句话：

```text
请先读取 https://raw.githubusercontent.com/ai-azhou/see-your-home/main/chat/read-prompt.md ，按里面的说明处理我上传的户型图；打不开就读 https://raw.giteeusercontent.com/gevoll/see-your-home/raw/main/chat/read-prompt.md
```

如果 Chat 回答它打不开链接、或者没按说明给出一大段代码，就换 B。

**B. 整段粘贴（Chat 不能联网时）**：

1. 打开[读图提示词 read-prompt.md](read-prompt.md)，点文件右上角「Copy raw file」（复制原始内容）。不要从渲染好的网页上手动框选复制，格式会乱。
2. 粘进对话框，在同一条消息里上传户型图，发送。
3. **粘不下**（提示词约 1.5 万字，有的 Chat 单条消息有长度上限）：点「Download raw file」把 `read-prompt.md` 下载下来，当附件上传，连同户型图一起发，再写一句「按附件里的说明处理这张户型图」。

Chat 会先用一两句话说它看到的是哪类图、打算怎么读，再讲路线图，然后给出一大段代码（方案），最后用白话说读到了什么、哪些是推断、要你确认的问题，以及「下一步你可以」。

## 第 2 步：复制方案

找到回复里以 `{` 开头的那段代码，点代码块右上角的「复制」按钮。

- 一定要复制**整段**。代码块很长，往下滚到最后，确认它以 `}` 结尾。
- Chat 说「分成了几段」时，按顺序把每一段都复制下来，拼在一起。
- **以后每次都用最新那份。**

## 第 3 步：粘进工具，放上户型图

1. 双击打开 `try-your-home.html`。
2. 点首页的「粘贴方案」（已经打开过方案的，在顶栏菜单里），把刚才复制的整段贴进去，点「载入方案」。前后的说明文字和代码块标记会自动去掉。
3. 第一次会提示「方案里引用了底图 户型图.png，点这里导入户型图」：点提示里的「**导入户型图**」，选你发给 Chat 的同一张户型图。这样会沿用 Chat 估出来的比例和位置。之后每一轮再粘贴新方案，工具会保留已经放上的底图（提示「底图沿用当前的图片」），不用再导入。

## 第 4 步：看叠图和 3D，回答问题

**看叠图**：读出的墙、门窗画在你的户型图上面。

- 彩色墙带压在原图的墙上、门窗落在原图的门窗位置，说明读对了。
- **整张都朝一个方向错开、或大小不一样**：多半只是底图的比例和位置是估的，不是结构读错了。打开「底图」，用「两点定比例」在图上点一条已知长度的两端（比如总尺寸线），输入真实长度，再拖动底图对齐。这一步不改结构。
- **只有某面墙、某扇窗对不上**：这才是读错了，交给 Chat 改。

**看 3D**：切到 3D，用「斜视」「俯视」「平视」转着看。

**回答问题**：Chat 第一轮一般问 3–5 个问题，比如「哪些墙是承重墙」「这条虚线是不是梁」「层高多少」。知道就直接答；不知道就说「不确定，按最可能的来」，它会保留推断，不会当成确定的事。你也可以在工具「待核对」里答。

**有问题时**：点「**复制问题给 Chat**」，工具会把校验出来的错误、对不上的地方、你在「待核对」里答过的问题整理成一段文字，贴回同一个对话。后面可以补一句自己的话，比如「北墙那扇窗应该更靠右」。Chat 逐条修好，再给一份完整方案，回到第 2 步。

## 简版方案：Chat 写不对完整方案时

有的 Chat（尤其是快速模式、推理最低档）写不对完整方案：标记写错、墙是空的、门写成一张关系表。这时它会改给一份**简版方案**，回复里会先说一句「这是简版方案」。简版只有房间（矩形或多边形）和「哪两间房之间有门」，粘进工具时，工具按房间自动补墙和门洞。

工具顶部会出一条醒目的「简版方案」说明，可以收起；收起后标题区一直有一个「简版」标记，点它能再展开说明。

**简版的局限**：

- 墙是工具按房间边线推测的：两间房共用的边当隔墙（120 mm），最外圈当外墙（240 mm）。都标成「推测」。
- **没有窗**。「待核对」里会有一张「窗户没有读出来，请在工具里自己加」。
- 门都开在两间房共用的那段墙正中间；入户门开在那间房最长的一段外墙中间，「待核对」里会请你确认位置。
- 房间之间有重叠或缝隙，会出问题卡。
- 方案里不带底图的比例和位置，导入户型图后要用「两点定比例」和拖动底图对齐。

**为什么会这样**：这是网页 Chat 的模型能力有限造成的，不是提示词或工具的问题。

**想要更准确的结构**：在 Chat 里打开「深度思考 / 长思考」这类模式，新开对话重试；或者用装了 Skill 的 Agent 版（见[仓库首页](../README.md)），Agent 版一律写完整方案。

**在工具里补窗、改门**（在「原始」模式下做，算纠正读图，不算改造）：

1. **加窗**：左侧工具栏点「门窗」（快捷键 `D`），在顶部的类型胶囊里选「窗」「落地窗」「飘窗」等，鼠标移到墙上会出预览，点一下放下。放不下时工具会提示原因（墙太短、空当不够）。
2. **调尺寸和位置**：放下后它是选中的，右侧检查器里改「宽」「离地」「洞顶」「离 A 端」，窗可以设「分扇」；也可以直接沿墙拖动。
3. **改门**：点选那扇门，沿墙拖到对的位置，或在检查器里改「离 A 端」「宽」；类型可以在七种里换（平开门、推拉门、门洞……）；平开门还能改「铰链」和「开向」（用房间名说，比如「开向 次卧」）。门放错了墙，选中按 `Delete` 删掉，再用「门窗」工具在对的墙上放一扇。
4. 改完想让 Chat 接着改，点「复制方案给 Chat」贴回去。

## 第 5 步：试拆墙、改门窗

1. 在工具里选中想动的墙或门窗（按住 Shift 可以多选）。
2. 点「交给 Agent」，写一句想做什么，比如「把这面墙拆掉，客厅和书房打通」。复制出来的文字，贴给同一个 Chat。
3. Chat 改完给出完整方案，照第 2、3 步粘进工具，切到「改造」模式看改完的样子，「对比」模式看前后差别。

- 动的是外墙、承重墙，或者承重情况不清楚的墙时，Chat 会先问你一次「确定要试吗」。你说确定，它才写进方案。这只是看效果，不代表可以施工。
- 交接文字里有几行写着「运行 validate」之类的命令，那是给命令行 Agent 的，Chat 会忽略，你不用管。
- **你在工具里自己改过**（拖过墙、答过问题、对过底图）：先点「**复制方案给 Chat**」，把复制的方案和你的话一起贴给 Chat，告诉它「以这份为准」。这份不带户型图的编码，不会撑爆对话。不然它会按自己记得的旧版本改。

## 第 6 步：出改造清单 PDF

有改造以后，在工具顶栏点「导出」→「改造清单 PDF」，预览后下载。可以拿去和家人、设计师当面聊。

## 第 7 步：想看装好的感觉，导出白模图去生图

1. 在 3D 里用「平视」转到想看的角度。
2. 左侧工具栏点「白模」，再点「导出图片」，背景选「纯白」、画幅选「16:9」，点「导出 PNG」。生图模型用 16:9 不容易重新构图。
3. 打开[生图提示词 image-prompt.md](image-prompt.md)（一句话启动也行：「请先读取 https://raw.githubusercontent.com/ai-azhou/see-your-home/main/chat/image-prompt.md ，按里面的模板帮我写提示词；打不开就读 https://raw.giteeusercontent.com/gevoll/see-your-home/raw/main/chat/image-prompt.md 」），挑模板 A（只用文字描述风格）或模板 B（再加一张你喜欢的室内照片），替换方括号里的内容。
4. 把提示词和图片一起发给一个**能生成图片**的 Chat。

出来的图是效果示意，尺寸以平面和立面为准。墙、窗、门的位置不对，就再出一次，或者换个模型。

## 常见问题

**Chat 的输出被截断了，代码没写完怎么办？**
回复它：「输出被截断了，按精简规则从头重新输出完整 JSON。」它会去掉像素框、缩短说明后重来；还放不下就分段给，你按顺序拼起来。

**粘贴方案时报格式错误怎么办？**
多半是没复制全（少了结尾的 `}`），或者 Chat 在代码里写了省略号、注释。先检查是不是整段都复制了；还不行，就把报错原文贴给 Chat，说「工具报这个错，请修好重新输出完整 JSON」。能打开但校验有错误的，用「复制问题给 Chat」。工具认出 Chat 给的 JSON 格式根本不对（没有格式标记、外面套了一层、墙是空的这类）时，「复制问题给 Chat」会复制一段「你上次输出的方案 JSON 格式不对，工具读不了」，后面带简版规则和模板，贴回去 Chat 就会改给简版。

**Chat 说它看不了图怎么办？**
先确认图片真的传上去了（对话里能看到缩略图）。有的 Chat 要先切到支持看图的模式或模型；还是不行，就换一个能看图的 Chat。不要把图上的内容打字告诉它代替看图，它会读不准。

**Chat 没提「改改你的家」，反而说要帮你画 SVG、写网页看 3D，怎么办？**
回复它：「按提示词开头的硬规矩回答。」它一般会改口，给出下载和使用「改改你的家」的固定步骤。也可以不等它，直接照这份说明「你需要准备」里的下载方法和第 2–4 步操作。它自己画的图没经过工具校验，也不能叠在原图上核对。

**Chat 改着改着，别的地方也变了？**
回复它：「只改我说的，其余逐字照上一版，id 不要变。」再让它重新输出。用工具「对比」模式能看出哪里变了。

**和 Agent 版有什么差别？**
内容规矩一样：同一套读图方法、同一种方案格式、同样的「不是施工图」。差别在动手能力：Agent 版自己量像素、自己校验、自己出叠图和 3D 白模图、生图后自动打分；网页版只能看图写字，校验、叠图、3D、导出图片都在工具里点，像素位置是估的，底图可能要你在工具里对齐一下。

## 隐私

- **户型图会发给你用的那个 Chat 服务**，按那家服务的规则处理。介意的话，上传前把图上的小区名、楼栋号、房号裁掉或涂掉，不影响读结构。
- **工具本身不联网**：try-your-home.html 在你的浏览器里运行，方案和图片只在你的电脑上。
- 「复制方案给 Chat」不带户型图；工具导出的 JSON 文件里可能带着户型图，把文件发给 Chat 等于再发一次这张图。
- 白模图和效果图也会发给对应的 Chat 服务，发不发由你决定。
