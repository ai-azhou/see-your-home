# 生图跑位 · 结论（10-29）

> 回答本人 10-29 早的问题：工具导出白模，交给生图模型出「感觉图」时，模型会改墙、改窗（跑位）。用白模、提示词、参考图这些办法，能不能改善？
>
> 依据：资料调研 `生图跑位/资料.md`（46 条引用，已独立核对并修订）；小实验 `生图跑位/实验.md`（客厅，走 Lovart）和 `生图跑位/libtv-包/`（主卧，走 LibTV 直连）。证据包 `生图跑位/evidence/`。每格只有 2 张图，下面的比例只能说明方向，不能当精确数字用。

## 一句话

**能改善，而且有一个现成的办法：把白模、深度图、线稿三张一起当参考图给模型。** 两个机位、两个模型、两个平台，结果都没跑位。

但这个办法只管住了「线的位置」，管不住「东西是什么」。像素级锁住门窗，闭源模型做不到（官方文档自己就这么写 [7][12]）。要像素级锁住，得走遮罩或开源结构控制，这一档这次没测成。

## 实验结果

### 自动跑位分 S

S 的口径：输入白模自己算 1，越高越准。

| 办法 | Nano Banana Pro | Seedream 4.5 |
|---|---|---|
| M0 基线：10-28 的提示词 | 客厅 0.80 / 0.72；主卧 L 0.96 / 1.03；主卧 T 0.58 / 1.00 | 客厅 0.08 / 1.07；主卧 L −0.08 / 0.03；主卧 T −0.02 / −0.02 |
| M1 严格提示词 | 客厅 0.84 / 0.64；主卧 T 0.83 / 0.50 | 客厅 0.06 / −0.01；主卧 T −0.06 / 0.99 |
| M2 结构图、风格图分开给 | 客厅 0.80 / 0.82；主卧 T 0.91 / 0.59 | 客厅 0.92 / −0.03；主卧 T 0.94 / 1.05 |
| **M3 白模 + 深度 + 线稿** | 客厅 0.97 / 0.98；主卧 T 0.88 / 0.59（加了窗帘） | **客厅 1.39 / 1.39；主卧 T 1.05 / 1.17** |
| M4 编辑模型（Qwen） | 客厅 0.43 / 0.76；主卧 T 0.15 / 0.19（对齐后 S* 0.97 / 1.00，整张有平移缩放） | — |

主卧的平台标注：L = Lovart，T = LibTV 直连。

### 读法

1. **跑不跑位，模型影响最大。**
   - Seedream 不给结构图时，14 张里 9 张跑位，跑法都是**整张重新构图**：机位后退、墙被推远，主卧还有一张连窗都变了。
   - Nano Banana Pro 不给结构图也基本守得住，最多有轻微偏移。
   - Seedream 基线跑位，在 Lovart（平台后台会改写提示词）和 LibTV（直连、原样发送）上一模一样，说明**原因是模型，不是平台**。
2. **结构图最有效。** Seedream 加了白模、深度、线稿以后 4/4 都没跑位，线位几乎逐条对上。
3. **严格提示词基本没用**：Seedream 照样跑位，0/2、1/2。**结构图、风格图分开给**时好时坏：客厅 1/2，主卧 2/2。
4. **编辑模型**：没改结构，但整张图有平移缩放，LibTV 上的 Qwen 编辑最高只出 1360×768。
5. **新问题：Nano Banana Pro 会自己加窗帘。** 加了结构图也照样加，压住了窗框，提示词里「不增添软装」这句它没听。模板要把「不加窗帘、百叶」写明。
6. **本地开源（SD1.5 + ControlNet）只锁住了线，没锁住东西**：门窗被画成了墙板、柜门，而且自动打分看不出来。

### 自动打分加重试管不管用

不过关（S 低于 0.6）就重出 1 张：客厅的跑位格从 3/11 降到 2/11，平均每格 1.36 张。

它防得住「整张重新构图」，防不住「窗变柜门」「加窗帘」。打分要补一项：门窗区域还是不是窗，看不看得到窗外。

## 资料的结论（和实验互相印证）

- **闭源编辑模型都不承诺像素级保结构。**
  - OpenAI：遮罩「完全基于提示」[7]；
  - BFL：FLUX.2「按语义理解结构」，叫用户别期待像素级匹配 [12]；FLUX.1 的 Canny / Depth 已经标为弃用 [14]。
- **结构条件（ControlNet 一类）有论文证据能提高对齐，但只是软约束**，不是像素锁定 [1][2]。我们本地那 4 张印证了这一点：线对上了，东西变了。
- **要遮罩外严格不变，靠的是「回贴」**：出图后把遮罩外的像素换回原图。这是后处理，闭源模型的输出也能用。
- **保结构档的候选**（这次都没测）：
  - 国内云端：只找到万相 2.1 通用图像编辑有像素遮罩，0.14 元一张，免费 500 张，但遮罩重绘和线稿生图是两个调用，不能合在一起用 [26]；
  - 本地开源：Qwen-Image-2.1 配 Fun-ControlNet-Union，能吃一张控制图加一张遮罩 [20][21]，只是峰值内存约 46 GB，本机 48 GB 刚够 [44]。
- **LibTV 的 21 个图像模型都没有遮罩或结构控制输入**（见 `libtv-包/models.md`），保结构档在 LibTV 上走不通。

## 给用户的推荐

**普通档**（闭源模型，普通人就能用）：
- 模型：Nano Banana Pro 优先；Seedream 4.5 只在给了结构图时用。
- 输入：白模、深度图（近白远黑）、线稿（白底黑线），三张按顺序给。
- 提示词：用 `prompts/P3-结构条件.txt` 模板，补两句——「输出 16:9 横图」和「不加窗帘、百叶、纱帘」。
- 出图后自动打分，S 低于 0.6 就重出，最多 2 次。还不过就交给人看。
- 图上标「效果示意，尺寸以平面和立面为准」。

**保结构档**（开源或带遮罩的模型）：下一轮再测。测法写在 `实验.md` §7：
- 换新底模，加分割图、遮罩重绘；
- 试万相 2.1 的遮罩编辑，要本人申请 API key；
- 本地 Qwen-Image-2.1 + Fun-ControlNet-Union。

## 对工具和 Skill 的决定

1. **要加「生图素材包」导出。** 导出这些：
   - 白模（写死画幅，室内机位补天花）；
   - 线稿，白底黑线、黑底白线各一张，**同一面墙的分段接缝要合并掉**（Seedream 会把接缝画成板缝）；
   - 逆深度图（近白远黑），加一张 16 位毫米版；
   - ADE20K 色板的分割图 [34]；
   - 每扇门窗单独编号的遮罩；
   - 相机参数，带画面里看得到的门窗清单（推荐提示词靠它自动填）。

   格式先按所引模型卡的约定来 [31][34]，再按目标模型验证。这部分已经写进开源任务书 O1 §4，由 plan-cli 的软件渲染器出。Skill 和工具以后共用这一套。
2. **D3 遗留的选择**：透明背景导出时，窗户默认画成实心浅灰，保留半透明作选项。实验里白模的窗都是实心的，没发现问题。
3. **生图 Skill 分两档**，和本人定的一致：
   - 普通档：照上面的推荐写成步骤，加上自动打分和重试；
   - 保结构档：等下一轮实验。

   按「Skill 不夹带内容」的规矩，Skill 里**不写死推荐哪个模型**，只写怎么挑（能不能传多张参考图、能不能传结构图、有没有遮罩）。上面这几个模型名只作为实验记录放进证据。

## 补充实验：执行包 2（10-29 下午，LibTV 直连，25 张全部出图）

数据在 `生图跑位/libtv-包2/`，有 `scores.json` 和两张拼图。PM 逐行目视过。每格 2 张，只能看方向。

| 组 | 结果 |
|---|---|
| **G：GPT（Lib Image 2.5 Pro）只给白模（M0）** | **4/4 守住**，S 0.81–1.01，和 Nano Banana Pro 一个水平 |
| G：GPT 白模 + 深度 + 线稿（M3） | **反而变差**：S 0.36 / 0.81 / 0.58 / −0.06，2 张整体平移缩放，还自己加了衣柜。多张结构图会把 GPT 弄糊涂 |
| **S：加「我喜欢这种感觉」风格照片（M7）** | Nano Banana Pro 4/4 守住；Seedream 3/4，客厅那张有一张重新构图；GPT 0/4，整个房间被重新诠释 |
| S：风格跟没跟上 | Nano Banana Pro、Seedream 明显带上了暖木、陶土、斜阳的感觉。但 Nano Banana Pro 会**用力过猛**，把陶土色从点缀刷成了整面墙，所以墙面主色和照片的色差（ΔE 7–12）反而比没给照片的奶油风对照组（ΔE 5–11）大。GPT 配色最贴（主卧 ΔE 2–3），代价是结构跑位 |
| S：风格照片的结构有没有漏进来 | **24 张里一张都没有**：没有拱门，主卧左墙也没冒出落地窗 |
| **C：提示词写明「不加窗帘」（M3b）** | Nano Banana Pro **4/4 都没加窗帘**，这一句管用。但客厅有 1 张跑位（S 0.05），这是 Nano Banana Pro 第一次跑位，所以它也不是绝对保险，自动打分加重试还得留着 |

**对推荐的修正**：
- **不同模型要配不同的输入**：
  - Nano Banana Pro、Seedream：白模、深度、线稿三张都给；
  - GPT：只给白模，不给深度和线稿，也不给风格照片。
  - 生图 Skill 不写死模型名，改成写一条流程：先给三张结构图，自动打分不过关，就退到只给白模再试。这条规则对所有模型都适用。
- **风格照片能用，而且不会把结构带进来**。但模型只学到「感觉」，颜色会被放大。Skill 里要提醒用户：「照片只取氛围，具体颜色以材料清单为准」。
- 提示词模板改用 P3b（加了「不加窗帘」那句）；带风格照片时用 P7。两份都在 `生图跑位/prompts/`。
